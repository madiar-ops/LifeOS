# ОБЩИЕ ПРАВИЛА

Перед началом любого этапа разработки:

1. Изучи MASTER_GUIDE.md.
2. Изучи TECHNICAL_SPEC.md.
3. Не изменяй архитектуру без объяснения.
4. Если есть несколько решений — сравни их.
5. Каждый этап заканчивай обновлением PROJECT_STATE.

Структура каждого ответа:

1. Анализ
2. План
3. Архитектура
4. Какие файлы будут созданы
5. Полный код
6. Объяснение
7. Проверка
8. Что делать дальше

# PROJECT OVERVIEW

Название проекта

LifeOS

LifeOS — это современная Full Stack AI SaaS платформа.

Это НЕ учебный CRUD.

Это НЕ pet project.

Это НЕ демонстрация отдельных технологий.

LifeOS должен выглядеть как настоящий коммерческий продукт.

Главная идея —

создать персонального цифрового помощника, объединяющего несколько сфер жизни пользователя.

Проект демонстрирует мои знания Full Stack разработки, архитектуры программного обеспечения, микросервисов, искусственного интеллекта и современных технологий.

# DEVELOPMENT GOAL

Во время разработки необходимо руководствоваться следующими принципами.

Главная цель —

НЕ написать проект максимально быстро.

Главная цель —

создать архитектурно грамотную систему.

Качество архитектуры важнее количества функций.

# ARCHITECTURE

Архитектура проекта —

Microservice Architecture.

React

↓

ASP.NET Core

↓

FastAPI

↓

PyTorch

Frontend никогда не обращается напрямую к AI.

Все запросы проходят через ASP.NET Core.

---

# RESPONSIBILITY OF ASP.NET CORE

ASP.NET Core является главным сервером проекта.

Он отвечает за

Авторизацию

JWT

CRUD

Работу с PostgreSQL

Работу с Firebase

Работу с пользователями

Работу с Dashboard

Вызов AI

Swagger

Validation

Business Logic

---

# RESPONSIBILITY OF FASTAPI

FastAPI отвечает исключительно за AI.

FastAPI не хранит пользователей.

FastAPI не хранит JWT.

FastAPI не работает напрямую с React.

FastAPI получает данные только от ASP.NET Core.

---

# DATABASE

Используется одна база данных.

PostgreSQL.

Все данные пользователя находятся в PostgreSQL.

---

# STORAGE

Все файлы пользователя хранятся в Firebase Storage.

Например

PDF

Изображения

Аватары

Документы

---

# AUTHENTICATION

Используется JWT.

Все защищенные маршруты используют JWT.

Пароли хранятся только в виде Hash.

Никаких открытых паролей.

Refresh Token обязателен.

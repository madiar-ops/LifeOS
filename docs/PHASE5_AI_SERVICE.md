## 3. Принятые решения

| Решение | Почему |
|---|---|
| **Внутренний ключ в заголовке `X-Internal-Api-Key`** | FastAPI не публичен и не знает про JWT. Единственный легитимный клиент — backend |
| **`hmac.compare_digest` вместо `==`** | Сравнение за постоянное время: по задержке ответа нельзя подбирать ключ посимвольно |
| **Пустой ключ → 500, а не «режим разработки»** | Сервис без ключа принимал бы запросы от кого угодно. Это отказ, а не удобство |
| **Модели грузятся один раз в `lifespan`** | Загрузка артефакта на каждый запрос — десятки миллисекунд против секунд. Это главное отличие инференс-сервиса от обучающего скрипта |
| **Отсутствие модели → 503 только у своего эндпоинта** | Сервис остаётся жив; недоступна конкретная функция, а не всё сразу |
| **`confidence` и `is_confident` в каждом ответе** | Прямое требование MASTER_GUIDE. Ответ без оценки уверенности недопустим |
| **Уверенность считается, а не задаётся константой** | Финансы — из `residual_std`, зафиксированного при обучении; здоровье — из `predict_proba` |
| **`contributions` — вклад признаков** | Модель не должна быть чёрным ящиком: видно, ПОЧЕМУ получился такой прогноз |
| **GradientBoosting, а не нейросеть, для табличных задач** | На таких данных бустинг стабильно не хуже, обучается за секунды и даёт готовые `feature_importances_` |
| **Одна показательная модель на PyTorch** | MASTER_GUIDE требует PyTorch в стеке. Честный ответ на защите: здесь он не даёт преимущества над бустингом, но демонстрирует владение инструментом |
| **`Pipeline(StandardScaler + RF)`, а не отдельный scaler** | Нормализация сохраняется внутри артефакта — исключает классическую ошибку, когда в проде данные подаются в другом масштабе |
| **Параметры нормализации сохраняются вместе с весами torch** | Без `mean`/`std` модель в проде получала бы данные в чужом масштабе и выдавала мусор |
| **`model.eval()` при загрузке** | Отключает Dropout — в инференсе он вреден |
| **Синтетические данные с фиксированным seed** | Датасеты Kaggle требуют аккаунта и ручной загрузки — проект не собрался бы «из коробки». Данные детерминированы, замена на реальные не требует правки кода |
| **Извлекающая суммаризация как запасной путь** | Она физически не может выдумать содержание — прямое следствие требования «AI не генерирует случайные ответы» |
| **Отказ вместо плохого теста** | Сгенерировать осмысленные варианты ответов статистически невозможно. Честнее сказать прямо |
| **Падение LLM не роняет эндпоинт** | Срабатывает локальный алгоритм, пользователь получает результат |
| **Разная уверенность у LLM и эвристики** | Эвристика не понимает смысл — только структуру. Пользователь должен видеть разницу |
| **Swagger отключён вне Development** | Сервис приватный, публиковать схему его API незачем |
| **CORS по умолчанию пуст** | Браузер не должен обращаться сюда напрямую |
| **Артефакты и датасеты не в git** | Воспроизводятся четырьмя командами; бинарники в репозитории не нужны |
| **Multi-stage Dockerfile + непривилегированный пользователь** | В финальный образ не попадают компиляторы; процесс не работает от root |

## 4. Проверка (чек-лист)

```bash
cd ai-service
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(48))"   # вписать в INTERNAL_API_KEY

python -m app.ml.training.generate_datasets
python -m app.ml.training.train_finance
python -m app.ml.training.train_health
python -m app.ml.training.train_wellbeing_torch

pytest
uvicorn app.main:app --reload --port 8000
```

- [ ] Все четыре скрипта обучения отработали, в `app/ml/artifacts/` появились файлы
- [ ] `pytest` → **18 passed**
- [ ] `GET /health` показывает все три модели `true`
- [ ] Swagger открывается на `/docs`
- [ ] `POST /finance/analysis` **без** заголовка ключа → **401** ← *ключевая проверка безопасности*
- [ ] С неверным ключом → **401**
- [ ] С верным ключом → **200**, в ответе есть `confidence`, `explanation`, `contributions`
- [ ] `/health-analysis` с плохим режимом → 3 фактора риска и низкая уверенность
- [ ] `/health-analysis` с хорошим режимом → `wellbeing_score` заметно выше
- [ ] `/study/summary` без `LLM_API_KEY` → `source: "extractive"`, конспект не пустой
- [ ] `/study/quiz` без ключа → `source: "unavailable"`, `is_confident: false`
- [ ] `/career/resume-analysis` находит навыки, отсутствующие в тексте резюме
